Agent activity log

The diff panel shows which files changed; the activity log shows what ran.Shipped›

Screenshots go straight into a Claude prompt.Shipped›

What's left, and what to check first

Seven items remain. None blocks daily use. Each starts with a check or a decision before planning.

Fast-mode toggle

Smallest item; the effort plumbing already does the work.

  1. Confirm fast mode's usage cost on your subscription
  2. Decide whether it is hidden by default
  3. Plan

Switch mode mid-session

Mode is fixed per role at start today.

  1. Capture a live set_config_option for mode on adapter 0.88
  2. Decide which roles may switch, and to what
  3. Plan

Fork into a worktree

Strategic: two approaches from one context.

  1. Capture session/fork on the Mac
  2. Add the capture to the fake-agent fixtures
  3. Then plan the worktree flow

Steer or queue while busy

Drafting during a turn already works.

  1. Capture the steering _meta shape
  2. Decide queue vs steer from the user's side
  3. Then plan

Extra folders, GitHub context, scrollback

Each needs a yes from you first.

  1. Extra folders: which roles need more than one repo?
  2. GitHub context: approve reading PRs, or keep it out
  3. Scrollback: worth it given /resume?
